# Data classification

Field-to-treatment table, per the engineering-standards rule 8 requirement to
classify every stored field before writing storage code. WakeIQ stores
everything locally, on-device, only (see [PRIVACY.md](../PRIVACY.md)): no
network stack, no `INTERNET` permission, no account or auth system, no
credentials of any kind. Every field below falls in the **plaintext**
bucket - none of it is a verify-only secret (no hashing applies) and none of
it is reproducible sensitive data such as PII, tokens, or financial data (no
encryption applies).

## Room database (`AlarmEntity`, table `alarms`)

| Field | Description | Bucket |
|---|---|---|
| `id` | Autogenerated row id | Plaintext |
| `hour`, `minute` | Alarm fire time | Plaintext |
| `daysOfWeek` | Recurrence days | Plaintext |
| `isEnabled` | Alarm on/off | Plaintext |
| `soundType`, `bundledSoundName`, `customUri` | Sound selection; `customUri` may point at a user-chosen local audio file, never transmitted | Plaintext |
| `peakVolume`, `smartWindowMinutes`, `rampDurationMinutes` | Ramp configuration | Plaintext |
| `motionSensitivity` | Motion-detection setting | Plaintext |
| `snoozeMinutes` | Snooze duration | Plaintext |
| `label` | User-entered free-text alarm name | Plaintext |
| `useSmartWake`, `colorIndex` | Display/behavior config | Plaintext |

## DataStore preferences (`app_prefs`)

| Field | Description | Bucket |
|---|---|---|
| `smart_window_minutes`, `ramp_duration_minutes`, `motion_sensitivity`, `snooze_duration_minutes` | Default values for new alarms | Plaintext |
| `blue_light_reduction_enabled`, `use_24_hour_clock` | Display preferences | Plaintext |
| `default_alarm_seeded` | Internal onboarding-state flag | Plaintext |

## Why no field needs hashing or encryption

- No authentication, no passwords, no client secrets exist anywhere in the
  app -> rule 7 (credential hashing) does not apply.
- No PII, auth tokens, financial data, or OTP secrets are collected or
  stored -> the alarm label is free text the user enters for their own
  device display, not personal data collected or transmitted anywhere.
- No network calls exist, so there is no transport to secure with TLS.

Re-classify this table before adding any field that could hold PII, a
credential, or anything transmitted off-device.
